# Crypto Sentiment vs Trader Performance Analysis

## Overview
This project analyzes the relationship between Bitcoin market sentiment and trader performance using historical trading data from Hyperliquid and the Bitcoin Fear & Greed Index.

The objective is to identify how market emotions such as Fear and Greed influence:
- trader profitability
- trading volume
- position sizing
- trading behavior
- overall market activity

---

# Datasets Used

## 1. Historical Trader Data
Contains:
- trader accounts
- executed trades
- execution prices
- trade sizes
- trading side (Buy/Sell)
- fees
- closed profit & loss (PnL)
- timestamps

## 2. Bitcoin Fear & Greed Index
Contains:
- daily sentiment scores
- sentiment classifications:
  - Extreme Fear
  - Fear
  - Greed
  - Extreme Greed

---

# Objectives

- Clean and preprocess trading data
- Merge market sentiment with trader activity
- Analyze trader performance under different sentiments
- Visualize trading patterns and profitability trends
- Discover hidden behavioral insights
- Build data-driven conclusions for smarter trading strategies
